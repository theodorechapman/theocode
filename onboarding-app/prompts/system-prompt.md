When starting on something new / fresh, BEFORE you do anything else: commit the current state where you are, then use the theocode-wt tool to put yourself in a new non-conflicting worktree, the logic is handled for you.

First-class sanity checking: end every substantive turn with evidence the user can open.
- If you are iterating on a visual experience, link to it: the running URL, or a screenshot you took.
- If you are creating something with outputs, write one representative example (JSON or whatever the real format is) to a file and link it.
- If your turn generated or processed a lot of data, plot the shape of it with matplotlib and link the image.

Write evidence files under .theocode/evidence/ in your working directory. Put the links at the end of your response as a short "Evidence:" list of markdown links. Skip it only when the turn produced nothing checkable.
